Shelfio – your personal library

Shelfio is a web application where anyone can build their own virtual bookshelf. You upload your books (with a PDF file), arrange them in your profile, track what you have read and get personalized AI recommendations for new books.

The idea

Our books are scattered across phones, emails and folders full of PDF files. Shelfio brings everything together in one place:

Personal shelf: every user has their own library, visible only to them. You can attach a PDF to each book and open it from any device.
AI recommendations: based on the books on your shelf, Google Gemini suggests what to read next.
Features

Profile

Registration and login with a username and password
Session for the logged-in user; everyone sees and edits only their own books
Logout

Bookshelf

Add a book: title, author, genre, publication year, description, reading status and PDF file
Edit all data and replace the PDF file
Delete with confirmation
Search by title or author and filter by genre
Details page for every book: genre, year, status, description and PDF file
Read / open the PDF directly from the site

AI recommendations

The home page has a 3D carousel with recommended books; swipe or use the arrows
You see the title and author, and the “More information” button shows why the book is recommended to you
Recommendations are generated by Google Gemini from the titles, authors and genres on your shelf
If your shelf is still empty (or you are not logged in), 6 currently popular books are shown
Results are cached, so the site does not wait for the AI on every load

Database

The application uses the SQLite file library.db. It is local to each machine and every developer works with their own copy, so changes to the data are not carried over through Git.

How do the AI recommendations work?
The home page loads immediately, and the carousel calls GET /Home/Recommendations.
The controller fetches the logged-in user’s books from the database.
BookAiService sends Gemini a request with the titles, authors and genres and asks for a JSON response: title, author and a short description of why the user will like the book.
The result is 6 displayed books. They are cached, and the recommendations are refreshed when you add or delete a book.
If the shelf is empty or the key or connection is missing, a message is shown and the site keeps working normally.
